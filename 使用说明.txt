osvsharp —— OSV/视频 清晰帧批量提取工具 v1.3.1
================================================

【这是什么】
从 DJI Osmo 360 的 .OSV 文件（或普通 mp4/mov/mkv 等视频）中，
自动挑出清晰帧并导出为 JPG 图片：
  · 解码优先用显卡硬解（NVIDIA CUDA → Vulkan → D3D11VA，自动探测，全部
    失败时退回 CPU 软解）
  · 每隔 N 帧取一小窗口，只保留窗口内"拉普拉斯方差"得分最高（最清晰）
    的那一帧，模糊帧、抖动帧自动淘汰
  · 可选动态抽帧间隔（"变化阈值">0 启用）：画面与上一张出图帧的变化
    攒够阈值才出图，变化快自动加密、静止自动放稀，相邻出图帧的画面
    变化量大致恒定，给三维重建（SfM）喂图最合适
  · 双目 360 视频（OSV）两路分别导出到 cam0/ 和 cam1/，文件名用源视频
    帧号命名，两路同帧号即同一时刻，方便后续拼接/建模配对
  · 抽帧编码时同步把每帧画面圆外涂黑：切掉鱼眼黑边和紧贴黑边的失焦
    模糊环，涂黑比例可自己设置（见下方"涂黑%"）；涂黑并入编码滤镜，
    单次编码无二次损失，几乎不增加耗时

【快速开始】
1. 解压整个文件夹（osvsharp.exe 必须和 ffmpeg.exe 在同一目录）
2. 双击 osvsharp.exe 打开界面
3. 把一个或多个视频拖进窗口（或点"添加文件"）
4. 双击列表中的文件可预览内容：弹出 12 格缩略图（按视频时长均匀
   取样），并显示时长、分辨率、双目/单路信息——U 盘里一堆没有规律的
   文件名，先预览再决定处理哪个。
   预览优先读取视频同目录下的同名 .LRF 低清代理文件（大疆官方方案，
   2048×1024 已拼接全景，秒开）；没有 LRF 时直接从原视频抽帧
5. 点"开始提取"，等进度条走完
5. 结果输出在每个视频旁边：与视频同名的 _sharp 文件夹
       例：D:\拍摄\CAM_xxx_D.OSV  →  D:\拍摄\CAM_xxx_D_sharp           cam0 05.jpg、cam1 05.jpg ……
           sharpness_cam0.csv（每帧评分记录；双目两轨共用布点，只记 cam0）

【不确定涂黑范围？】
先选中列表里的视频（或光标停在第一行），点「涂黑测试」：自动提取
每路第一帧，生成 85~99% 的涂黑对比大图（每格标有百分数，双目文件
cam0/cam1 各一组）。在图上点击想要的那一格，主窗口「涂黑%」就会
设为该值，再点「开始提取」正式批量。

【界面参数】
  抽帧间隔    每隔多少源帧输出一张（默认 8；25fps 视频约等于每秒 3 张）；
              动态间隔模式下不参与
  锐度窗口    每个输出位置往前多少帧里选最清晰的一帧（留空=自动，约为
              间隔的一半；填 1 表示不做模糊筛选，到点就截）；
              动态间隔模式下不参与
  变化阈值    大于 0 即启用动态抽帧间隔：每帧与上一张出图帧比平均灰度
              差（MAD），变化攒够阈值才结算出图，期间仍挑最清晰的一帧，
              最低清晰度照常过滤。变化快出图密、静止自动变稀，间隔自动
              在 4~32 帧之间伸缩（25fps ≈ 每秒 0.8~6 张）。定值方法：
              先用 0 跑一遍，看 sharpness_camN.csv 的 diff 列——静止段
              数值小、走动段数值大，把阈值定在两者之间（实测 8K 行走
              素材：8≈默认密度，12 约减半，常用 5~12）；填 0 = 固定
              间隔模式
  最低清晰度  得分低于该值的帧即使窗口内最优也不输出（0=不设门槛；
              开机抖动/曝光爬升段可用它剔除，建议先跑一遍看 CSV 分数
              分布再定，本机测试数据下 200~400 比较合适）
  JPEG质量    输出图片质量，同 ffmpeg -q:v，数字越小越清晰、文件越大
              （默认 2；常用 2~5）
  涂黑%      抽帧编码时同步把每张图中心圆外的像素涂黑：圆心=画面中心，
              保留半径=百分数×短边÷2，切掉鱼眼黑边和紧贴黑边的失焦
              模糊环；涂黑区不产生图像梯度，SfM 特征点天然落不进去，
              等价于给三维重建喂 mask。默认 95，数字越小切得越多
              （保留面积≈百分数的平方：95%→90%、88%→77%）；参考：
              Osmo 360 样帧实测清晰边界约 93%，默认 95 为实测选定值；
              拿不准就用「涂黑测试」按钮看对比图再定；填 0 = 不涂黑。
              涂黑仅对双目 OSV 文件生效：普通单流视频（普通 mp4 等）
              没有鱼眼圆外黑边，自动跳过涂黑
  输出目录    留空=输出到各视频旁边；也可统一指定（批量时每个视频一个
              子文件夹）

【说明】
  · 双目文件（.OSV）输出 cam0 + cam1 两路；单路普通视频只有 cam0
  · 文件按源帧号命名（00005.jpg = 源视频第 5 帧，0 起）；双目两轨
    共用 cam0 的选帧布点，cam0/cam1 同号严格配对（轨1 跳过评分，
    不生成 cam1 的 csv）
  · 每次输出前自动清掉输出目录里上次运行留下的旧帧图片（只删本工具
    按帧号命名的 .jpg，其他文件不动），换参数重跑不会新旧混杂
  · 处理约 1 分钟的 8K 双目 OSV 需 1~2 分钟（有硬解时）；CPU 软解约慢 5 倍
  · 中途可点"停止"，已输出的文件保留

【命令行（可选）】
把视频拖到 osvsharp.exe 图标上即可直接处理（无界面）；或：
  osvsharp.exe 视频1.OSV 视频2.OSV [选项]
  选项：-s 抽帧间隔  -k 锐度窗口  -m 最低清晰度  -q JPEG质量
        --diff 变化阈值（>0 启用动态间隔，忽略 -s/-k）
        --min-gap / --max-gap 动态模式最小/最大出图间隔帧（默认 4/32）
        -mask 涂黑半径%（0=不涂黑）  -o 输出目录
        --hwaccel cuda|vulkan|d3d11va|none  --nopause
  例：osvsharp.exe CAM_xxx_D.OSV -s 4 -m 300
      osvsharp.exe CAM_xxx_D.OSV --diff 8

【常见问题】
  Q：提示 cannot run ffmpeg？
  A：ffmpeg.exe 没和 osvsharp.exe 放在同一文件夹。整个压缩包一起解压
     即可，无需安装任何东西。
  Q：速度很慢？
  A：说明没探测到硬解，正在 CPU 软解（日志第一行会显示 hwaccel: none）。
     独显/NVIDIA 驱动正常时一般会自动启用 CUDA。
  Q：想剔除开机时的模糊/偏暗画面？
  A：设置"最低清晰度"。先跑一遍，打开 sharpness_camN.csv 看 score 分布，
     把门槛定在明显偏低和正常帧之间。
  Q：导出的帧数比预期多/少？
  A：调"抽帧间隔"：输出张数 ≈ 总帧数 ÷ 间隔。
  Q：画面变化剧烈（快走/转身）时固定间隔不够密、静止段又太密？
  A：用"变化阈值"启用动态间隔。先跑一遍看 CSV 的 diff 列分布定阈值，
     调大更稀、调小更密；急速运动段受最小间隔 4 帧保护，帧数不会失控。
